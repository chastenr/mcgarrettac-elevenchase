## Fonts and presentation assets

Archivo, DM Sans, and Lora are self-hosted using `next/font/local`. Font binaries came from Google Fonts (`fonts.gstatic.com`); the SIL Open Font License files are retained in `public/fonts/`. Family source repositories: [Archivo](https://github.com/google/fonts/tree/main/ofl/archivo), [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans), and [Lora](https://github.com/google/fonts/tree/main/ofl/lora).

`public/images/hd/ac-repair.jpg` and `public/images/hd/local-home.jpg` (3000 × 2000) are derived from the files of the same name above. Each is a 2× Lanczos resample with light sharpening, made so the full-width heroes stay crisp on high-density screens. No content was added, removed, or retouched, and the originals are unchanged.

The service-area artwork is an original decorative SVG illustration, explicitly labeled as an illustration rather than a service boundary. Preview JPGs in `public/previews/` are browser screenshots of the actual implemented homepages. They are captured from a 1440 × 1240 viewport at 2× pixel density, with reduced motion enabled, and cover the first 3720 CSS pixels of each page (2880 × 7440 image pixels), so the selection page can scroll them. Regenerate them with `node tests/capture.mjs` after changing either concept.
